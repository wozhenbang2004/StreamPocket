# 0.5.1 · 待发布

- 修复自绘开关缺少点击能力的问题，真实触摸可切换设置，并补齐键盘与无障碍点击入口。
- 修复启动自动检查被 24 小时限制挡住的问题：每次真正从后台打开都会检查，应用内切页和旋转不重复请求。
- 网络失败不会占掉当天的检查机会；下次打开会重试，重新开启自动检查开关会立即检查。
- 已发现的版本会保存并在进程重建后恢复；临时断网时保留已有更新入口。
- “稍后”仅推迟本次打开期间的提示；关闭自动检查后不再弹出新版本提醒。
- 检查调度移到应用前台生命周期，快速离开主页或直接恢复其他页面也能触发。

# 0.5.0 · 2026-11-04

- 下载页新增整队暂停与继续；新加入的任务遵守队列暂停状态，整队继续保留手动暂停项。
- 等待项可设为下一项或移至队尾；多选暂停、继续、仅重试失败/中断和移除停止记录，移除支持撤销。
- 视频库新增继续观看、未看、已看与收藏筛选，可与搜索、来源和合集组合；支持单项/批量收藏。
- 合集支持改名、删除和批量移出，移出可撤销；删除合集保留视频、进度、标记和剪辑引用。
- 深度浏览后刷新已加载的完整视频范围，返回时保留列表位置；合集移出撤销在切换页签后仍有效。
- 单播放器新增显式画中画、单次/单个循环/连续播放、真实可用音轨及内嵌字幕选择；连续播放遵守当前筛选并在末项停止。
- Media3 升级到 1.11.1；配套升级编译工具，最低仍支持 Android 7.0。
- 保留首批 X 缺格式恢复、播放重试、异步暂停/取消和下载支持更新回滚修复。
- 58 个套件共 409 项回归、83 项下载核心更新检查与 5 项进程停止检查通过；Lint 0 错误、74 警告；Android 15 模拟器的实际媒体与系统画中画流程通过。
- 原包名与签名发布，versionCode 31，支持覆盖更新。签名成品摘要、构建证据及实机/实网未验证边界见 [发行与验证](RELEASE_STATUS.md)。

# 更新记录

完整版本和安装包见 [版本记录](https://github.com/wozhenbang2004/StreamPocket/releases)。

## 0.3.3 更新

- 修复链接输入框无法触摸聚焦的问题，可直接输入、编辑和长按粘贴。
- 播放器支持更大画面区域内下滑下一条、上滑上一条，控制层显示时也可刷视频；放大后拖动只移动画面。
- 双指缩放至 5×，放大后显示“复原画面”，控制层和进度条保持原大小。
- 更多操作新增双视频分屏：选择第二路、上下或左右排列、独立播放/进度/缩放，一次只启用一路声音；返回单路保留准确位置。
- X 登录解析缺少视频画质时，有条件尝试公开接口；保留账号、失败记录和正确视频序号，区分无画质与网络/代理错误。

## 0.3.2 更新

- 剪贴板先预览链接与来源，再勾选解析；手动粘贴去重追加，保留未提交草稿。
- 输入时显示有效链接数量，无效内容就近提示；提交后收起空输入区，优先展示解析结果与画质。
- 视频库增加三列网格，保留双列和列表；缩小卡片更多、播放图案，保留点击范围。
- 播放画面中间向下滑可切换到当前筛选和排序中的下一个视频，保存上一条进度；更多菜单提供同一入口。
- 解析失败保留链接、原因和重新解析入口，重开应用仍可重试；按网络、权限、文件缺失等原因给出恢复提示。

## 0.3.1 更新

- 视频库突出封面，完整显示横竖画面；统一标题、时长、续播状态和辅助信息，减少画面上的操作干扰。
- 来源筛选改为可多选的胶囊入口，支持应用、取消、清除及返回恢复；搜索、排序和视图切换统一在顶栏。
- 播放器采用渐隐控制层，更多操作按标记剪辑与观看设置分组；倍速选择更紧凑，按住画面可临时 2×，松手恢复。
- 新建下载压缩重复标题与间距，粘贴、解析操作并列，输入时显示识别到的链接数量；保留草稿、解析顺序和待下载结果。

## 0.3.0 更新

- 统一应用内面板、菜单、按钮、开关、单选、输入和进度样式，适配浅色与深色。
- 待下载结果采用紧凑列表；下载筛选支持点击与横向拖动，解析、重试和下载继续按队列处理。
- 调整视频库、播放器工具、剪辑、账号与设置界面；片段移除后可撤销。
- 更新页重新排版，格式化显示更新说明，并显示实际安装版本、提供安装信息复制。
- 应用内更新采用独立的系统安装会话，校验暂存内容后进入确认；取消或失败时保留明确的重试入口。
- 视频库与下载页使用一致的播放入口，移除封面共享转场，避免静态封面遮挡播放画面。

## 0.2.12 更新

- 解析改为独立的持久队列。多次粘贴、分享和接受剪贴板链接都追加处理，保留正在重试的任务、失败项、草稿与已有结果。
- 解析结果留在“待下载”，可逐项选画质、单独加入下载或全部加入队列；关闭再打开仍可继续。
- 剪贴板提醒缩为底部轻提示，点击“加入解析”后才处理，不自动下载或询问替换现有内容。
- 优化视频库播放的画面衔接与视频绘制，减少播放和缩略预览之间的资源竞争；补充画面启动失败时的重试提示。
- 保留 0.2.11 的下载顺序、批量识别、平台请求间隔与限流冷却；修正 CI 的 Android SDK 安装配置。

行为、边界和测试范围见 [下载流程](docs/DOWNLOAD_FLOW.md)。
